# Asset del sito

Metti qui le immagini del sito.

## Logo (necessario)

Carica il file del logo **esattamente con questo nome**:

```
assets/logo.png
```

È il logo mostrato in cima all'hero (`index.html`, elemento `.hero-logo`).
Finché il file non è presente, il riquadro del logo resta nascosto in automatico
(grazie all'attributo `onerror`), quindi il sito non si rompe.

Suggerimenti:
- Va bene il PNG quadrato con sfondo bianco che hai già.
- Se disponi anche di una versione **PNG con sfondo trasparente**, ancora meglio:
  si integra in modo più pulito, soprattutto in tema scuro.
- Nome alternativo? Se preferisci un altro nome, cambialo anche in `index.html`
  (cerca `assets/logo.png`).

## Come caricarlo su GitHub (30 secondi, dal browser)

1. Vai su: https://github.com/otticaclienti/sito-estetica-clienti/tree/claude/sito-estetica-clienti-hq7mwu/assets
2. In alto: **Add file → Upload files**
3. Trascina il file del logo e **rinominalo `logo.png`**
4. **Commit changes** sul branch `claude/sito-estetica-clienti-hq7mwu`

Il sito su GitHub Pages si aggiorna da solo in circa 1 minuto.
